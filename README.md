# StudyBuddy

## About

Study Buddy is a student collaboration platform designed to make it easier for students to find help with coursework, personal projects, and other academic topics.

Students can create profiles that identify the subjects and skills they are knowledgeable in, as well as areas where they are looking for assistance. The platform uses this information to connect students with others whose skills and needs are a good match.
